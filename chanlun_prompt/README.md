# 缠论 (Chanlun) GLM5 提示词系统

本目录包含为 GLM5 大模型设计的缠论 K 线分析系统提示词。

## 文件说明

| 文件 | 说明 |
|------|------|
| `system_prompt.md` | 完整系统提示词（角色定义 + 缠论公理体系 + 分析流程） |
| `few_shot_examples.md` | 少样本示例，展示输入输出格式和推理链条 |
| `usage_guide.md` | 接入指南：如何在 GLM5 API 中组合使用这些提示词 |

## 设计原则

1. **公理化定义** — 所有概念（包含关系、笔、线段、中枢、背驰）均给出严格数学定义，避免歧义
2. **分步推理** — 强制模型按「K 线合并 → 分型 → 笔 → 线段 → 中枢 → 背驰 → 买卖点」顺序逐步推导
3. **链式验证** — 每一步要求模型自检，列出不满足条件的反例再确认
4. **少样本锚定** — 提供典型案例的完整推理过程，锚定输出格式和推理深度
